💡 常见问题 ​

如何选择实现？ ​

  • Fetch - 推荐用于现代浏览器和 Node.js 18+
  • Axios - 需要更多功能或支持旧版本浏览器

如何配置重试？ ​

typescript
const request = new Request(
  new FetchRequestor(),
  {
    retry: {
      maxRetries: 3,
      retryDelay: 1000
    }
  }
);

如何添加认证？ ​

typescript
request.interceptors.addRequestInterceptor({
  onRequest: (config) => {
    config.headers = {
      ...config.headers,
      'Authorization': `Bearer ${token}`
    };
    return config;
  }
});
